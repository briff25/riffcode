# 🚗 License Plate Game

The road-trip classic, on a live map of the US. Tap each state as you spot its plate, watch the map fill in, and chase all 50 before you get there.

**Live:** [riffcode.brianriffle.com/apps/license-plate/](http://riffcode.brianriffle.com/apps/license-plate/)

![License Plate Game](../../Images/projects/license-plate.jpg)

## Built with

- Claude Code
- D3.js
- TopoJSON
- Vanilla JS

Static HTML/CSS/JS — open `index.html` in a browser, no build step.
